# frontend

Власниця: Катя. React + TypeScript + Vite, MapLibre GL, Three.js, Tailwind. Хостинг Vercel.

Три сторінки: головна (глобус і пожежі), "Як ми дослідили", "Своя пожежа".

Демо-дані читаються з `data/demo/` (`index.json` і по папці на пожежу з `result.json`, `cells.json`, `optical.png`).

Застосунок ще не створений. Створити його можна так:

```bash
npm create vite@latest . -- --template react-ts
```
